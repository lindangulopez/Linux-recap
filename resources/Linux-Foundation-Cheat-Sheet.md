# **Linux Foundation OSS/Linux/Git Specialization**

This specialization teaches the skills needed to work effectively in open-source projects, using Linux, Git, and developer tools. You learn system-level development, command-line proficiency, scripting, version control, and collaboration workflows.

**Core Skills Across the Specialization:**

* Open source principles, contribution models, and licensing
* Linux system usage and administration
* Command-line proficiency and Bash scripting
* Filesystem management and permissions
* Software compilation, packaging, and debugging
* Git version control and distributed workflows

---

## **Course Summaries & Key Takeaways**

### **1. Open Source Software Development Methods**

* Philosophy and benefits of open source software
* Governance models, leadership, and community roles
* Contribution best practices and CI/CD concepts
* Licensing types and copyright considerations
* Project sustainability, documentation, and community health

### **2. Linux for Developers**

* Linux basics: kernel vs OS, distributions, history
* System structure and filesystem layout
* Command-line navigation and file management
* System administration: users, groups, permissions, logs
* Package management and monitoring system resources

### **3. Linux Tools for Developers**

* Advanced command-line utilities and text processing
* Bash scripting for automation
* File metadata, symbolic links, and filesystem navigation
* Compiling programs and debugging
* Software packaging and system programming concepts
* Running and managing Java applications on Linux

### **4. Using Git for Distributed Development**

* Git setup, architecture, and basic commands
* Branching, merging, and rebasing workflows
* Working with remote repositories and upstream/downstream
* Collaboration: pull requests, code review, patch management
* Conflict resolution and best practices for team development

## **Master Cheat Sheet**

### **Open Source Principles**

* Collaborate transparently and responsibly
* Respect community guidelines and contribution rules
* Understand permissive vs copyleft licenses

---

### **Linux Command-Line Essentials**

* Navigation: `cd`, `ls`, `pwd`
* File operations: `cp`, `mv`, `rm`, `mkdir`, `touch`
* View content: `cat`, `less`, `head`, `tail`
* Text processing: `grep`, `wc`, `sort`, `awk`
* Pipes & redirection: `|`, `>`, `>>`

---

### **Linux Administration**

* User/group management: `useradd`, `groupadd`, `passwd`
* Permissions: `chmod`, `chown`
* Symbolic links: `ln -s <target> <link>`
* System monitoring: `top`, `htop`, `ps`, `df`, `du`, `free`
* Logs: `/var/log`, `journalctl`, `dmesg`

---

### **Bash Scripting**

* Shebang: `#!/bin/bash`
* Variables: `VAR=value`
* Conditionals: `if …; then …; fi`
* Loops: `for …; do …; done`, `while …; do …; done`
* Functions: `my_func () { … }`

---

### **Compiling & Debugging**

* Compile C: `gcc source.c -o output`
* Debug: `gdb <program>`
* Java: `javac MyClass.java` → `java MyClass`

---

### **Git Essentials**

* Setup: `git config --global user.name "Name"` / `git config --global user.email "email"`
* Initialize repo: `git init`
* Clone repo: `git clone <url>`
* Stage: `git add <file>`
* Commit: `git commit -m "Message"`
* Status & diff: `git status`, `git diff`

---

### **Branching & Merging**

* Create branch: `git branch <branch>`
* Switch: `git checkout <branch>`
* Delete: `git branch -d <branch>`
* Merge: `git merge <branch>`
* Rebase: `git rebase <branch>`

---

### **Working Remotely**

* Remotes: `git remote -v`
* Fetch: `git fetch origin`
* Pull: `git pull origin <branch>`
* Push: `git push origin <branch>`
* Forks & pull requests for contributions

---

### **History & Review**

* View log: `git log --oneline --graph --decorate`
* Detailed log: `git log -p`
* Show commit: `git show <commit-hash>`

---

### **Collaboration Best Practices**

* Commit small, logical units
* Write clear, descriptive messages
* Keep branch structure clean
* Frequently sync with upstream
* Use code reviews and patches for collaboration
