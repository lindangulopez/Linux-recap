## Rust Courses Overview

### Module 1 - Rust: Workflow Optimization

* **Progress:** 1h 27m of videos left, 2h 20m of readings left, 1 graded assessment left
* **Focus:** Optimize Rust development workflow using programming suggestions, Copilot prompts, and GitHub Codespaces
* **Learning Objectives:**

  * Use GitHub Codespaces, including collaborative features, for efficient project development
  * Use Copilot prompts to generate code snippets and accelerate workflow
  * Apply programming suggestions to enhance Rust coding experience
  * Set up your code editor to develop Rust efficiently and understand errors quickly

---

### Module 2 - Rust: Control Flow, Error Handling, and Functions

* **Focus:** Essential concepts of control flow, error handling, and functions in Rust
* **Learning Objectives:**

  * Create and utilize functions in Rust, including unit functions, return values, and using arguments
  * Apply break and continue statements to modify loop behavior
  * Use the match control flow construct for pattern matching
  * Handle errors using panic and robust error-handling mechanisms
  * Apply the borrowing concept to manage memory safely and efficiently

---

### Module 3 - Rust: Data Structures and Types

* **Focus:** Understanding structs, strings, vectors, enums, and exhaustive matches
* **Learning Objectives:**

  * Explain structured data and its importance in Rust
  * Define and work with structs, including associated functions and constructors
  * Define and manipulate strings (`String` and `str`)
  * Define enums, use variants, and combine with vectors for flexible data modeling
  * Handle exhaustive matches for enums and reinforce learning with practical assessments

---

### **[Module 4](https://www.coursera.org/learn/rust-fundamentals/home/module/4)** - Rust: Advanced Topics (Testing, Documentation, and Libraries)

* **Focus:** Code organization, testing, documentation, and library development
* **Learning Objectives:**

  * Verify code correctness using doctest
  * Organize code using public and private modules for proper encapsulation
  * Manage access to struct fields with public/private distinctions
  * Organize test files and write effective tests, including for private code
  * Document Rust code effectively to enhance readability and maintainability
