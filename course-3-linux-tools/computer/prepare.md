# Preparing Your Computer for Linux Course Work


✅ **Key Takeaway:**
You have flexibility in choosing the system—physical, virtual, or cloud. Focus on ensuring required tools are installed, and remember that graphical interfaces are optional. Virtual machines and cloud instances offer safety and flexibility for learning Linux.

---

### 1. Choice of System

* You can use **your own Linux installation**—any distribution you are comfortable with.
* Occasionally, you may need to install missing programs or packages. Use your distribution’s standard package management tools (like `apt` for Ubuntu/Debian or `dnf` for Fedora/RHEL).

---

### 2. Graphical Environment Not Required

* All course work can be done **without a graphical interface**.
* You can work on a **remote machine** via SSH or other remote login methods.

---

### 3. Physical vs. Virtual Machines

* You can use:

  * **Physical computer** running Linux
  * **Virtual machine** under a hypervisor such as:

    * VMware
    * Oracle VirtualBox
    * KVM
* Virtual machines are preferred for beginners:

  * Lower risk of system damage
  * Performance is sufficient for exercises
  * Easy to create snapshots and restore system state

---

### 4. Cloud Options

* **Amazon Web Services (AWS)** offers cloud-based virtual machines (“instances”) that can be accessed remotely.
* The **AWS Free Tier** provides up to one year of free access for learning purposes.
* Advantages of using AWS:

  * Experiment with multiple Linux distributions
  * Safely practice system administration
  * Supplement local hardware setups

---

### 5. Preparation Steps

1. Verify your computer or virtual machine is ready.
2. Install any missing packages using your Linux distribution’s package manager.
3. Decide whether you will work locally or on a remote/cloud machine.
4. Optionally, follow guides for AWS Free Tier setup if you want cloud access.
